# Ashley Portfolio

개인 포트폴리오 사이트의 첫 버전입니다. 실제 경력과 프로젝트 정보가 제공되지 않은 영역은 업데이트 예정으로 표시했습니다.

## 파일

- `portfolio/index.html`: 자기소개, 프로젝트, 연락처
- `portfolio/style.css`: 반응형 디자인
- `portfolio/script.js`: 저작권 연도 갱신

## 미리보기

`portfolio/index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요 없습니다.

## 내용 수정

`portfolio/index.html`에서 Ashley 이름, 소개, 관심 분야, 경력, 프로젝트 카드, 연락처를 수정하세요. 프로젝트와 경력은 실제 정보로 교체한 후 활용하세요.

## GitHub Pages

저장소 Settings → Pages에서 Deploy from a branch, main, /(root)를 선택하고 저장하면 사이트 경로는 https://ashley900630-dev.github.io/APR/portfolio/ 입니다. Pages 설정은 별도로 활성화해야 합니다.
